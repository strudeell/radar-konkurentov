# Радар конкурентов

Ежедневно снимает публичные страницы 17 конкурентов на рынке речевой аналитики РФ,
сравнивает видимый текст со вчерашним и присылает владельцу недельный дайджест в
Telegram. Отдельно и сразу — алерт, если у кого-то изменилась цена или появился
новый тариф.

Нейросеть в сборе не участвует: обнаружение изменения — это `diff` двух текстовых
снимков. Бесплатно, детерминированно, ничего не выдумывает.

Методика и обоснование каждого решения — в
[04-tehnicheskij-plan.md](../Радар%20конкурентов%20—%20контекст%20для%20разработки/04-tehnicheskij-plan.md).
Результаты разведки источников — в [FAZA-0-OTCHET.md](FAZA-0-OTCHET.md).

## Как запускать

Разведка (Фаза 0, повторный прогон — раз в квартал, когда конкуренты
перестраивают сайты):

```
python tools/stage_a_home.py
python tools/stage_b_pages.py
python tools/stage_c_verify.py
python tools/stage_d_build_yaml.py
```

ВКонтакте — токен живёт час, обновляется без человека:

```
python vk_token.py refresh
python vk_token.py test
```

## Секреты

**В репозитории секретов нет и быть не должно.**

Доступ к ВК даёт единственный файл — `vk_tokens.json`. В нём `access_token`,
`refresh_token`, `id_token` и `user_id` владельца аккаунта. Он закрыт в
[.gitignore](.gitignore) **до** того, как в папке появился git: файл, попавший
хотя бы в один коммит, остаётся в истории навсегда, и лечится это только отзывом
токена.

Скрипты `vk_token.py` и `tools/check_vk.py` секретов не содержат — они читают
токен из этого файла или из переменной окружения `VK_TOKEN`. В `config.yaml`
секретов нет и не появится: там только контактный ящик и подпись бота.

Что `.gitignore` при этом **не** защищает — разобрано в
[FAZA-1-OTCHET.md](FAZA-1-OTCHET.md), раздел «Что это НЕ защищает». Коротко:
от копирования папки целиком он не спасает — отдавайте наружу репозиторий, а не папку.

Свой токен получают один раз, руками — порядок в [VK-TOKEN.md](VK-TOKEN.md):

```
python vk_token.py auth <ID приложения>
```

## Вежливость обхода — не опция

Бот представляется на каждом запросе:

```
RadarBot/0.1 (+https://okk-ai.ru; competitive monitoring; contact: example@gmail.com)
```

Пауза 2 секунды между запросами к одному хосту, `robots.txt` уважаем, таймаут
20 секунд, 2 повтора. Мы наблюдаем публичные страницы, а не долбим чужой сайт.
Ящик из подписи должен реально читаться: жалоба владельца сайта, оставшаяся без
ответа, превращается в блокировку. Ящик меняется одной строкой `contact_email`
в [config.yaml](config.yaml).

Из этого следует, что конкуренты знают о наблюдении: подпись честная и называет
компанию. Это осознанный размен, разобран в [FAZA-0-OTCHET.md](FAZA-0-OTCHET.md).
