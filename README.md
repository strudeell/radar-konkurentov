# Радар конкурентов

Программа, которая каждый день заходит на сайты конкурентов, запоминает, что там
написано, и сравнивает с тем, что было вчера. Если что-то изменилось — сообщает.

Раз в неделю, по понедельникам, владелец получает в Telegram одно сообщение: что
поменялось у конкурентов за неделю, по каждому игроку отдельно, со ссылкой на
страницу. Если у кого-то изменилась цена или появился новый тариф — сообщение
приходит сразу, не дожидаясь понедельника.

Рынок — речевая аналитика в России, 19 конкурентов. Семнадцать из них программа
обходит сама, двоих приходится смотреть глазами. Почему — в конце этого файла.

## Как это устроено, если совсем коротко

Со страницы берётся не весь её код, а только тот текст, который видит человек:
заголовки, описания, цены. Этот текст сохраняется в файл — дальше такой файл
называется **снимком**. Завтра делается такой же снимок и сравнивается со
вчерашним. Разница между ними и есть изменение.

Нейросети в этом нет. Сравнение двух текстов — обычная операция: она ничего не
стоит, работает одинаково каждый раз и не выдумывает того, чего на странице нет.
Искусственный интеллект нужен только на последнем шаге — объяснить человеку,
какие из сорока найденных изменений важны. Это делается в обычном чате с
ассистентом, отдельный платный доступ для этого не нужен.

## На каком этапе проект

Работа разбита на семь фаз — это просто этапы, идущие по порядку. Так они
названы в плане, и так же названы файлы отчётов.

| Фаза | Что это | Состояние |
|---|---|---|
| 0 | Проверить, что источники вообще отдаются | Сделано 18.08.2026: 49 страниц, 11 каналов в соцсетях |
| 1 | Собрать каркас проекта | Сделано 18.08.2026 |
| 2 | Научиться снимать и сохранять страницы | Следующий |
| 3 | Научиться находить разницу между снимками | Не начат |
| 4 | Отделить важное от обычного и слать в Telegram | Не начат |
| 5 | Поставить на расписание | Не начат |
| 6 | Неделя обкатки на живых данных перед боевым запуском | Не начат |

Шестая фаза выглядит необязательной, но пропускать её нельзя. Без недели обкатки
система заваливает владельца мелочами, и через две недели её перестают читать.

## Как поставить

Нужен Python версии 3.12 или новее. Дальше три команды:

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Первая создаёт отдельную папку под библиотеки, чтобы они не смешивались с тем,
что уже стоит на компьютере. Вторая её включает. Третья ставит четыре библиотеки,
которые нужны проекту.

Проверено на Python 3.12.4 под Windows. Версии библиотек закреплены — через год
всё поставится ровно таким же, каким работает сейчас.

## Как запускать

**Проверка источников.** Она уже сделана. Повторять нужно примерно раз в квартал,
когда конкуренты перестраивают сайты и старые адреса перестают работать:

```
python tools/stage_a_home.py
python tools/stage_b_pages.py
python tools/stage_c_verify.py
python tools/stage_d_build_yaml.py
```

**ВКонтакте.** Доступ к нему живёт один час, поэтому перед каждым обходом его
надо обновить. Человек для этого не нужен, программа делает это сама:

```
python vk_token.py refresh
python vk_token.py test
```

Вторая команда показывает, от чьего имени работает доступ и сколько постов в
каждом из четырёх отслеживаемых сообществ. Отвечает — значит, всё в порядке.

## Про секреты

Доступ к ВКонтакте от вашего имени даёт **один-единственный файл** —
`vk_tokens.json`. Кто его получит, тот сможет читать и писать в ВКонтакте от
вашего лица, пока доступ не отозван. Больше нигде в проекте этого доступа нет:
программы `vk_token.py` и `tools/check_vk.py` только читают его из этого файла,
внутри них пусто. В `config.yaml` секретов нет и не появится — там почтовый ящик
и подпись бота.

Файл закрыт от git — системы, которая хранит все версии проекта. Закрыт списком
[.gitignore](.gitignore), и важен порядок: список составлен раньше, чем git вообще
появился в папке. Причина простая — git помнит всё, что в него попало, навсегда.
Если файл с доступом попадёт туда хотя бы один раз, удалить его следующим
действием мало: он останется в истории, и лекарство одно — отозвать доступ и
получить новый.

Что защита при этом **не** закрывает — разобрано в
[FAZA-1-OTCHET.md](FAZA-1-OTCHET.md). Если коротко: от копирования папки целиком
она не спасает, поэтому наружу отдают репозиторий, а не папку.

Получить доступ заново, если старый испортился, — одна команда, порядок расписан
в [VK-TOKEN.md](VK-TOKEN.md):

```
python vk_token.py auth <номер приложения>
```

## Как бот ведёт себя на чужих сайтах

На каждом запросе он представляется:

```
RadarBot/0.1 (+https://okk-ai.ru; competitive monitoring; contact: example@gmail.com)
```

Плюс пауза две секунды между обращениями к одному сайту, соблюдение правил,
которые сайт выставляет для роботов в файле `robots.txt`, ожидание ответа не
дольше 20 секунд и две попытки при сбое.

Это не формальность. Мы смотрим страницы, открытые всем, и не создаём сайту
нагрузку, а у его владельца должна быть возможность написать нам вместо того,
чтобы просто заблокировать. Отсюда два следствия, и оба надо принять заранее:

- **Ящик из подписи должен реально читаться.** Жалоба, оставшаяся без ответа,
  превращается в блокировку. Поменять ящик — одна строка `contact_email`
  в [config.yaml](config.yaml).
- **Конкуренты узнают, что мы за ними смотрим.** Подпись честная и называет
  компанию. Это сознательный размен, он разобран в
  [FAZA-0-OTCHET.md](FAZA-0-OTCHET.md).

## Что придётся смотреть глазами

Три источника автоматически взять не вышло. Это проверено на практике, а не
предположение:

- **aistudio.yandex.ru** — на всех страницах стоит защита от роботов, картинка с
  проверкой. Раз в месяц открывать руками. Продукт в закрытом тестировании,
  публично меняется редко.
- **Канал Roistat в Дзене** — страница отдаёт пустую заготовку, текста в ней ноль,
  ленты у Дзена нет. Раз в месяц открывать руками. Ставить ради одного канала
  тяжёлую программу-браузер — размен не в нашу пользу.
- **call-intellect.ru** — сайт не отвечает вообще никому, проверено с двух разных
  интернет-подключений. Игрок помечен как мёртвый и из обхода исключён, но из
  списка не удалён: иначе через полгода кто-нибудь начнёт разбираться заново.
